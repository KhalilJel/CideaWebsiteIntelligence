# Cidea Website Intelligence Agents

Hermes is the top-level orchestrator.

## Layers

1. Firecrawl extracts website evidence.
2. Agent Reach supplies external/public context when configured.
3. JEV executes browser journeys when configured.
4. TypeSafe validates browser actions and observations.
5. Specialist audits evaluate UX, SEO, CRO, Design, Content, Performance and Trust.
6. Improvement Director ranks evidence-backed actions.

No recommendation should be treated as production ready without human review.
